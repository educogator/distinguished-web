# Pratonton v1.1

`home-public-{390,768,1440}.png` menunjukkan tema baharu di WordPress tempatan dengan
**replay kandungan awam** yang diperoleh melalui GET selepas pemasangan v1. Logo, menu,
tajuk, imej dan petikan datang daripada respons awam semasa; tiada login atau database
produksi digunakan. Tajuk “Under Maintenance!” sengaja dikekalkan seperti tetapan semasa.

`visual-notes-public-1440.png` menunjukkan pos Visual Note-taking sedia ada. `fixture-*`
ialah screenshot kandungan ujian sintetik yang berasingan, bukan kerja sekolah.

Grafik hero berbentuk nota/kod/audio ialah mockup konsep CSS asli, dilabel **Concept
illustration · Not student work**. Ia digunakan kerana imej hero TIFF semasa tidak serasi
dengan Chromium. Tiada foto Apple, fon Apple, UI proprietari atau logo rekaan digunakan.
Ilustrasi ini adalah dekorasi, bukan portfolio pelajar atau bukti aktiviti baharu.

Replay mengekalkan `content.rendered` dan rujukan media awam, bukan raw Gutenberg atau
metadata plugin peribadi. Oleh itu, screenshot ini menunjukkan pembetulan visual dan
integrasi tema dengan markup awam; ujian pada staging sebenar masih diperlukan sebelum
penggantian kod produksi. Imej dalam screenshot tidak dibundel sebagai fail media tema.
