# Anotasi hero v1.1.4

Ideas start here menggantikan slogan berulang dalam elips. Teks dan elips berwarna
biru dakwat #245b83. Caveat ialah fon tulisan tangan yang dibundel bersama lesen
SIL OFL 1.1, dimuat daripada repositori google/fonts (ofl/caveat). Tiada permintaan
fon pihak ketiga semasa pelawat membuka laman. Slogan utama dan pautan hero kekal.

Semakan PHP 29 fail, JavaScript, JSON dan WPCS lulus. Pemuatan fon disahkan dalam
Chromium tempatan pada 390px dan 1440px; ZIP lulus CRC. Suite penuh dan Safari
tidak diulang. Pemasangan produksi belum dilakukan.

Pasang ZIP v1.1.4 melalui Appearance → Themes → Add New → Upload Theme →
Replace current with uploaded, kemudian kosongkan cache. Untuk rollback, pasang
semula ZIP v1.1.3. Checksum disimpan bersama ZIP dalam dist/.
