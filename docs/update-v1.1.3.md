# Kemas kini hero v1.1.3

1 November 2026.

Slogan utama hero kini **Create What Matters**. Tiga butang menggantikan susunan
empat butang terdahulu:

| Butang | Halaman tujuan |
| --- | --- |
| Inspire | Teaching |
| Imagine | Learning |
| Impact | Showcase |

Tema mengambil halaman/pos awam sedia ada dan permalink WordPress sebenar; tiada
perubahan pada tajuk halaman, kandungan, menu utama atau URL asal. Butang Vision
serta pautan sementara ke Our story telah dikeluarkan daripada hero.

## Pengesahan

- 29 fail PHP, sintaks JavaScript dan theme.json lulus.
- WordPress Coding Standards: tiada ralat atau amaran.
- Chromium tempatan: tajuk tepat dan tiga pautan dalam susunan betul pada 360, 390,
  768, 1024 dan 1440px; tiada limpahan mendatar, tiada pelanggaran axe pada hero.
- Ketiga-tiga halaman tujuan tempatan mengembalikan HTTP 200.
- Pemasangan ZIP tempatan berjaya. CRC sah; 38 fail sepadan dengan sumber dan
  tema yang dipasang. Tiada perubahan produksi dibuat.
- Suite penuh terdahulu tidak diulang; Safari dan pembaca skrin manual belum diuji.

Pratonton dalam `previews-v1.1.3/` ialah replay kandungan awam tempatan, bukan
pengesahan pemasangan produksi. Nama laman mengikut data audit yang disimpan.
`screenshot.png` tema menggunakan fixture sintetik tempatan.
